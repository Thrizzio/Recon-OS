# Contributing Documentation

- **Purpose:** Host contributor-facing guidance beyond the essentials in
  [`CONTRIBUTING.md`](../../CONTRIBUTING.md).
- **Audience:** New and returning contributors.
- **When to update:** When a contributing process or expectation is added or changed.
- **Expansion:** Add setup guides, review checklists, and module onboarding here.

The root `CONTRIBUTING.md` is the entry point. This directory holds the longer-form material
that supports it.

## Contents

| Document | Status | Description |
| -------- | ------ | ----------- |
| `CONTRIBUTING.md` (repo root) | Current | Branch, commit, issue, and PR conventions. |
| Environment setup | Current | Install with pnpm and run `pnpm validate` (see `docs/getting-started/`). |
| Review checklist | Planned | What reviewers verify before approving. |
| Module onboarding | Planned | How to approach a first contribution to a module. |
